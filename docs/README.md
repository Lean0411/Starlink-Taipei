2. 如需詳細安裝，查看[安裝指南](./user-guide/installation.md)
3. 遇到問題？查看安裝指南中的故障排除部分

### 系統開發
1. 了解[系統架構](./technical/architecture.md)
2. 查看[API 文件](./technical/api-reference.md)

## 📝 文件維護

### 文件更新原則
- 保持文件與程式碼同步更新
- 使用清晰的標題和結構
- 提供實用的範例程式碼
- 包含故障排除章節

### 貢獻文件
歡迎提交文件改進建議：
1. Fork 專案
2. 在 `docs/` 目錄下修改或新增文件
3. 提交 Pull Request

## 🔍 搜尋功能

使用 GitHub 的搜尋功能在文件中查找特定內容：
- 在專案頁面按 `t` 鍵快速搜尋文件
- 使用 `path:docs` 限定在文件目錄中搜尋
