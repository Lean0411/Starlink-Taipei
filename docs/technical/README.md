### 後端技術
- **Python 3.8+** - 核心計算引擎
- **Skyfield** - 衛星軌道計算
- **PyTorch** - 深度學習框架
- **NumPy/Pandas** - 數據處理

### 前端技術
- **R Shiny** - Web 應用框架
- **Plotly** - 互動式視覺化
- **Bootstrap** - UI 框架
