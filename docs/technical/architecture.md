# 系統架構

## 概述

Starlink 台北衛星分析系統採用分層架構設計，結合 R Shiny 前端、Python 計算引擎和深度學習模型。

## 核心組件

### 1. 使用者介面層

#### 簡化版界面 (`app_simple.R`)
- 單檔案 Shiny 應用
- 最少配置，一鍵啟動
- 適合初學者和快速分析

#### 完整版界面 (`app.R` + `ui.R` + `server.R`)
- 模組化設計
- 豐富的互動功能
- 支援進階配置

### 2. 應用邏輯層

#### Server 邏輯
- 處理用戶輸入
- 調用 Python 計算引擎
- 管理會話狀態
- 生成視覺化圖表

#### R Integration Service
- Python-R 橋接層
- 數據格式轉換
- 錯誤處理和日誌

### 3. 計算引擎層

#### 衛星分析引擎 (`satellite_analysis.py`)
主要類別：
- `SatelliteAnalyzer`: 核心分析類
- `OrbitPredictionEnhancer`: 深度學習增強
- `OptimalWindowDetector`: 最佳觀測窗口檢測

核心功能：
- TLE 數據下載和解析
- SGP4/SDP4 軌道傳播
- 可見性計算
- 覆蓋率分析

#### 預測服務 (`prediction_service.py`)
- 多時間尺度預測（1h, 24h, 7d）
- SCINet-SA 深度學習模型
- 預測不確定性量化
- 結果快取機制

### 4. 數據層

#### 輸入數據
- TLE 文件：衛星軌道元素
- 配置參數：位置、時間範圍等

#### 輸出數據
- JSON：結構化分析結果
- CSV：數據表格
- PNG：圖表圖片
- HTML：完整報告

## 技術棧

### 前端技術
- **R Shiny**: 互動式網頁框架
- **Plotly**: 互動式圖表
- **Leaflet**: 地圖視覺化
- **DT**: 數據表格
- **Bootstrap**: UI 框架

### 後端技術
- **Python 3.8+**: 核心計算語言
- **NumPy/Pandas**: 數據處理
- **Skyfield**: 天文計算
- **PyTorch**: 深度學習
- **Multiprocessing**: 並行計算

### 深度學習模型
- **SCINet**: 時間序列預測基礎架構
- **Self-Attention**: 長期依賴建模
- **Ensemble Method**: 物理模型與 AI 融合
