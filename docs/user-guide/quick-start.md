# Starlink 台北衛星分析系統 - 簡化版

一個專為一般用戶設計的簡單易用的 Starlink 衛星覆蓋分析工具。

## 快速開始

### 一鍵啟動

```bash
# 下載並啟動應用
Rscript quick_start.R
```

啟動後在瀏覽器中訪問：**http://localhost:3838**

### 系統要求

- **R 語言** 4.0 或更新版本
- **網路連接**（用於安裝套件）
- **瀏覽器**（Chrome、Firefox、Safari 等）

## 主要功能

### 1. 快速分析
- 點擊一個按鈕即可開始分析
- 自動使用台北地區最佳設置
- 三種預設分析時長：
  - 快速分析（30分鐘）
  - 標準分析（60分鐘）
  - 詳細分析（120分鐘）

### 2. 結果查看
- 清晰的數據展示
- 互動式圖表
- 簡單易懂的分析摘要
- 一鍵下載報告

### 3. 簡單設置
- 基本參數調整
- 預設台北座標
- 重置功能

## 使用說明

### 第一次使用

1. **啟動應用**
   ```bash
   Rscript quick_start.R
   ```

2. **開啟瀏覽器**
   - 訪問 http://localhost:3838
   - 等待頁面載入完成

3. **開始分析**
   - 點擊左側選單的「快速分析」
   - 選擇分析時長（建議選擇「標準分析」）
   - 點擊「開始分析」按鈕

4. **查看結果**
   - 分析完成後點擊「結果查看」
   - 瀏覽分析數據和圖表
   - 可下載報告作為記錄

### 常用操作

- **修改設置**：點擊「簡單設置」調整參數
- **重新分析**：在「快速分析」頁面選擇不同時長重新分析
- **下載數據**：在「結果查看」頁面下載報告或原始數據

## 輸出結果說明

### 主要指標

- **平均可見衛星**：分析期間平均可以看到的衛星數量
- **最大可見衛星**：單一時刻最多可見的衛星數量
- **覆蓋率**：有衛星信號覆蓋的時間百分比
- **平均仰角**：衛星在天空中的平均高度角

### 下載文件

- **分析報告**：包含所有主要指標的 HTML 報告
- **原始數據**：詳細的時間序列數據（CSV 格式）

## 疑難排解

### 常見問題

**Q: 啟動時提示套件未安裝？**
A: 系統會自動安裝必要套件，請確保網路連接正常並等待安裝完成。

**Q: 網頁打不開？**
A: 請檢查：
- 防火牆是否阻擋 3838 端口
- 是否有其他程式占用此端口
- 嘗試重新啟動應用

**Q: 分析結果看起來不對？**
A: 本簡化版使用模擬數據，如需真實衛星軌道計算，請使用完整版系統。

**Q: 如何停止應用？**
A: 在命令列中按 Ctrl+C 即可停止服務。

## 進階功能

### 命令列工具

如果您熟悉命令列操作，也可以直接使用分析腳本：

```bash
# 快速分析
python simple_analysis.py --quick

# 標準分析
python simple_analysis.py --standard

# 詳細分析
python simple_analysis.py --detailed

# 自定義時長
python simple_analysis.py --duration 90
```

### 切換到完整版

如果您需要更進階的功能，可以使用：

```bash
# 啟動完整版界面
Rscript start_full_app.R
```

完整版提供：
- 更多分析參數
- 真實衛星軌道計算
- 深度學習預測功能
- 詳細的技術指標

## 系統架構

- **前端**：R Shiny 網頁應用
- **後端**：簡化的 Python 分析引擎
- **數據**：模擬衛星覆蓋數據
- **輸出**：JSON 和 CSV 格式
